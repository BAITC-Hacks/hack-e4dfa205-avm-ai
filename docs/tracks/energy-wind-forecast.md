# Трек: Agentic AI для прогнозирования выработки ВЭС

**Владелец задачи:** Самрук-Казына

## Суть
Agentic AI, который прогнозирует **почасовую выработку ветроэлектростанции на 24–48 часов**.
Агент сам получает архивный прогноз погоды по координатам турбин и обновляет расчёт
на каждый день тестового периода — **февраль 2026**.

## Как понимаем задачу
- Вход: координаты турбин, (вероятно) история выработки, архивные прогнозы погоды.
- Выход: ряд `timestamp → MW` на горизонт 24–48 ч, пересчитываемый ежедневно (rolling).
- «Агентность»: агент сам решает, какие данные подтянуть, запускает прогноз,
  проверяет результат и сохраняет его — без ручных шагов.

## Черновой пайплайн
1. **Погода** — архивный *прогноз* (не факт!) по координатам на дату выпуска прогноза,
   чтобы не было утечки будущего. Ключевые поля: скорость и направление ветра
   на высоте ступицы (~100 м), порывы, температура, давление (плотность воздуха).
2. **Признаки** — скорость ветра в кубе, sin/cos направления, час суток,
   агрегация по турбинам / по площадке.
3. **Модель** — базовая: кривая мощности турбины; основная: градиентный бустинг
   поверх погодных признаков.
4. **Агент** — цикл по дням февраля 2026: получить погоду → прогноз → метрика → отчёт.
5. **Демо без ключей** — закэшированные погодные данные в репо.

## Вопросы к ТЗ
- Какие данные дают: история выработки / SCADA, установленная мощность, модель турбин?
- Метрика оценки: MAE, RMSE, nMAE от установленной мощности?
- Формат сдачи прогноза: CSV, API, дашборд?
- Какой источник архивных прогнозов погоды допустим?
