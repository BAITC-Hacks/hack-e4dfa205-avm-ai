## Проверка взаимодействия

FastAPI раздаёт HTML, JS, CSS и изображения с того же origin, на который фронтенд отправляет относительные `/api/*`. Отдельный frontend-сервер и CORS для документированного запуска не нужны. `normalizeCity()` преобразует серверные поля `scope`, `pair`, `indicator_order` в структуру интерфейса. ## Воспроизводимость

Создано новое виртуальное окружение Python 3.12.8 внутри `.clean-check/review-20260923/`, скопированы файлы проекта без `.env`, зависимости установлены из `requirements.txt`. Код не переносился в другой репозиторий. После установки `pip check` вернул `No broken requirements found`.

Стандартная установка pip в ограниченном окружении застревала на записи глобального кэша. Стек показал `pip._internal.network.cache` → `NamedTemporaryFile`; с `--no-cache-dir` установка завершилась. README содержит эту проверенную команду. Конфликты сторонних пакетов глобального Python не относятся к чистому окружению проекта.

Первый снимок прошёл 60 тестов. **Итоговый снимок 1d4cdcc: 63 теста прошли за 2,26 секунды**, одна DeprecationWarning от связки Starlette/AnyIO. `pip check` прошёл. `scripts/demo.py` завершился с кодом 0 и `mode=template`; в выводе также 11 точек Парето. Команды выполнены из корня чистой копии её собственным Python, без `.env`. Новый полный индекс с Парето независимо пересобран в памяти и полностью совпал с файлом; все 11 точек валидны. HTTP-проверки и Chromium подтвердили таблицу выше. Чистая копия — новое окружение на этой машине, не отдельная новая ОС. После последних изменений перед сдачей нужно повторить запуск именно зафиксированного коммита.

### Что ещё мешает полностью воспроизводимой сдаче

- В `requirements.txt` зафиксированы прямые зависимости, но нет полного lock-файла транзитивных. Установка сейчас проходит; набор транзитивных версий со временем может измениться. Для строгого требования «все зависимости зафиксированы» нужен полный проверенный lock.
- Новый `static/patrol.js` и изображения патруля во время ревью были untracked. Если сохранить только изменение `index.html`, чистый clone получит ссылки на отсутствующие файлы. Проверять комплектность итогового коммита; ревью не делает commit/push.
- Нет проверки всего UI в штатной тестовой команде. 60 успешных тестов начальной версии не обнаружили ошибки истории чата, гонок и модалок.
