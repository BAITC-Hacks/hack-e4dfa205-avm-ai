# Найдено при автоматическом прогоне интерфейса (headless Chromium, 17:25)

Прогон: «Готовый сценарий» → «Объяснить» → закрыть окно советника → «Найти улучшение» → «Применить». Ошибок JS нет, 404 после `a321f92` нет. Шаги 1–3 проходят. Шаг 4 не проходит:

## 1. Критично для демо: после Escape советник больше не открывается — ИСПРАВЛЕНО 17:28 (Claude, одна строка в closeModal), прогон проходит полностью: «Применить» → 57,21, 3-е место из 694 395

- `static/app.js:434` — Escape вызывает общий `closeModal()`, а не `closeAdvisor()`. `closeModal()` не сбрасывает `state.advisorOpen`.
- `static/app.js:621` — `openAdvisor()` начинается с `if (state.advisorOpen) return;` → после закрытия окна через Escape (и, вероятно, через клик по подложке, если там тоже `closeModal`) кнопки «Найти улучшение» и «Открыть советник» молча ничего не делают до перезагрузки страницы.
- Воспроизведение: «Готовый сценарий» → «Объяснить» → Escape → «Найти улучшение»: `#modal` остаётся `hidden`, кандидатов нет.
- Минимальная правка (одно место): в `closeModal()` (строка 387) добавить `state.advisorOpen = false;` — тогда любой путь закрытия сбрасывает флаг. Либо в обработчике Escape вызывать `closeAdvisor()`, когда `state.advisorOpen`.
